# url-checker-python

Simple script to check urls defined in a `.txt` file. 

## AI and this project

There will be no AI used in this project beyond using, when required, deepseek to ask questions that do not tell me what to do, but simply assist me when I need to know "how do I run a request in Python" but that will only happen if Google fails, I am more likely to ask Google first, not because I am intentionally trying to be ineffecient, but because I am building the muscle to learn to use AI when I know how and I can only know how when I understand what to look for.
